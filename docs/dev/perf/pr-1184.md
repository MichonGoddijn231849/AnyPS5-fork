Title: `fix(recompiler): plan a bindless table entry that several T#s read`

### What

GTA V (PPSA04264) aborts in shader registration on `main` with

```
GetImageResource dword 0 is not a valid runtime value; chain: ReadConstBuffer(GetBufferResource(...),
ShiftLeftLogical32(ShiftRightLogical32(ReadConstBuffer(GetBufferResource(...), IAdd32(ShiftLeftLogical32(
IMul32(IAdd32(LoadAddressU32, LoadAddressU32), Immediate), Immediate), Immediate)), Immediate), Immediate))
```

The T# is read from a table at a key taken out of a material record (`(word >> s) << t`), the record found through
two scalar loads. `MatchTableOffset` takes that key, but `TryMakeTableImage` also required every one of the entry's
eight scalar reads to be used by the handle being planned and nothing else. When the shader samples the entry twice,
each read has a second user, a T# built from the same eight reads, so the table was refused and the T# fell through
to the runtime-value check above.

Every T# built from exactly the same eight reads now counts as a user of the entry, and each handle gets the same
table plan (one table source, one sampled image binding).

Tables wider than 16 slots are not part of this PR. #1789's heap sizing (the typed heaps sized by the runtime
metadata, the table slot count kept as its own `BindlessTableSlots`) is the base for that; on top of it, more slots
need only that constant raised and the image limits (`ShaderInfo::MaxImages`, the specialization ID spacing) moved.
GTA V's material tables fit 16 slots in our captures (64 and 128 slots change nothing visible), so it is left to a
follow-up.

### Tested

- Linux (lavapipe): `agc_shader_memory_tests` gains `verifyBindlessShiftedKey`, a compute shader that reads a record
  index through two scalar loads from a pointer in the SRT, takes the key from a 12-byte record at offset 8 as
  `(word >> 4) << 5` (GTA V's constants, from the table matcher's trace on our integration branch), and samples the
  table entry twice. It checks the plan (one whole-table source), the capture (the slots hold the
  table's entries, the `(key, slot)` mapping), and the compiled binding (one sampled image array holding the
  slots). Without the change it fails with the error above; with one sample instead of two, `main` already passes.
- Linux: on this branch `agc_shader_memory_tests` (both modes), `agc_driver_bindless_images_tests` and
  `agc_shader_device_profile_tests` pass; `tools/check_conventions.py --base d70b8998` passes.
- Linux, the full suite on our GTA V stack (main `d70b8998` with #2293, #1789's candidate, #1836, #1837, #1964,
  #1904, #1934) plus this change: 512 of 514. `guest_sce_net` needs the network; `agc_driver_storage_cache_budget`
  ran out of time under load beside a replay and passes alone (39 s).
- GTA V on that stack: not run yet (no GPU here).
